# Roadmap

The roadmap is evidence-gated, not feature-gated.

## Phase 0 — Research harness (current)

Deliverables:

- project charter/boundaries;
- research foundations/source index;
- failure-mode catalog;
- canonical schemas;
- private transcript ingest boundary;
- agent manifest/handoff;
- CI and data-integrity checks;
- first concept/problem/eval design.

Exit: ready to run R0 experiment.

## Phase 1 — R0 Sliding Window trajectory

Deliverables:

- deterministic Sliding Window Lesson IR;
- state/invariant reference model;
- 5–10 controlled problem variants split among baseline, guided, transfer, and delayed use;
- transcript normalization;
- learning-event extraction proposals;
- first complete Subject 001 trajectory;
- delayed retention follow-up;
- trajectory report with failures and counterevidence.

Exit: R0 criteria satisfied.

## Phase 2 — R1 within-subject replication

Deliverables:

- repeat experiments across multiple Sliding Window subtypes;
- compare representation operations;
- quantify assistance fading;
- document misdiagnoses and corrections;
- decide whether visuals, pseudocode, traces, or other representations deserve deeper investment.

Exit: evidence that procedure is repeatably useful for Subject 001, or explicit decision to simplify/stop.

## Phase 3 — Minimal learner product

Only if R0/R1 justify it:

- minimal session UI;
- deterministic visual renderer;
- code editor/runner;
- tutor orchestration separated from model prompts;
- private learner data store;
- staging deployment and smoke/eval suite.

Do not add rich media simply because models support it.

## Phase 4 — Second DSA family

Choose based on what the first study reveals, likely a structurally different family such as BFS/DFS, binary search, or trees.

Goal: test whether the representation-learning procedure generalizes across concept structure.

## Phase 5 — R2 second participant

Test procedure transfer to another learner.

The target is not to reproduce Subject 001's preferences. The target is to see whether the same observation/probe/intervention/evaluation protocol discovers a different useful learning path.

## Later possibilities

- audio/TTS explanations;
- validated generated storyboards/video;
- richer knowledge graph of concepts/prerequisites/representations;
- FOSSIL promotion/retrieval of durable findings;
- additional domains;
- multi-participant studies;
- adaptive policy learning.

Each later capability needs a reason tied to observed learning data.

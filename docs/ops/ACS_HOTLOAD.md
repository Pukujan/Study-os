## After cloning

Initialize the ACS submodule:

~~~bash
git submodule update --init --recursive third_party/agent-custom-setup
git -C third_party/agent-custom-setup rev-parse HEAD
~~~

The expected ACS gitlink is 264117398e7754d7e91076481cd664b5e197c1d4. Pinned PCM, CGM and OIO checkouts are external dependencies; they must not be copied into Study OS.

To validate the installed coordination surface with the certified CGM checkout:

~~~bash
python third_party/agent-custom-setup/modules/coordination/multi-agent-hotload/v0.1.0/scripts/hotload_check.py \
  --adopter-root . \
  --assignment .coord/assignment.json \
  --cgm-root /path/to/content-generation-modules
~~~

To validate OIO, run the pinned OIO installer with --target . --project-id Pukujan/Study-os --check. The release-train's scripts/check_manifest.py checks stack-manifest.json against its certified stack-releases.json.

The install was generated by tools/install_acs_hotloader.py with the upstream acs_install.py. Do not hand-write a replacement .coord lock or claim an installation is READY unless the checks pass.

## Agent authority

Study OS retains its existing arbiter, grok-bot@study-os, under docs/AUTHORITY.md. The ACS agent list is a role seed, not an authenticated live lease or a grant of merge/verdict authority. The initial boss lease is vacant; current authority must be checked against the GitHub-canonical issue/claim record before action. The check-in issue for this install is [#202](https://github.com/Pukujan/Study-os/issues/202).

The watchdog settings in the assignment describe the intended agent-less liveness contract. They do not by themselves schedule an active watcher. Configure and verify a scheduler separately before relying on automatic stale-seat detection.

OIO's default project priorities are placeholders until the Study OS owner maps priority meanings and account authority to the project's own workflows. Do not treat generic 1–100 levels as accepted Study OS policy.

All changes remain task-branch and PR-only, with required CI checks, receipts, and no direct changes to main. ACS adds coordination and issue intake; it does not own learner data, product decisions, or the research record.
